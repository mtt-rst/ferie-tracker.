FERIE TRACKER - PWA smartphone

PUBBLICAZIONE CON GITHUB PAGES
1. Crea su GitHub un nuovo repository, ad esempio "ferie-tracker".
2. Carica NELLA RADICE del repository tutti i file contenuti in questa cartella (non la cartella stessa): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
3. Nel repository apri Settings > Pages.
4. In "Build and deployment", Source: "Deploy from a branch".
5. Branch: "main" e cartella "/ (root)", poi Save.
6. Attendi la pubblicazione e apri dal telefono l'indirizzo HTTPS mostrato da GitHub Pages.
7. Android/Chrome: menu ⋮ > Installa app / Aggiungi a schermata Home.
   iPhone/Safari: Condividi > Aggiungi alla schermata Home.

DATI
I dati sono salvati nel localStorage del sito sul dispositivo. Chiudere l'app o riavviare il telefono non li cancella. Usa "Esporta backup" periodicamente e prima di cambiare telefono/browser o cancellare i dati del sito.
